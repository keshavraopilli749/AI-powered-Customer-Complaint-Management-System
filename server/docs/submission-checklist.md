# AIVOA Final Submission Checklist

Before submitting your project to the AIVOA review board, verify the following:

## 1. Code Repository
- [ ] The GitHub Repository is PUBLIC (or the interviewers are invited).
- [ ] The `main` branch contains all 15 sections of code.
- [ ] The commit history is clean and logical.
- [ ] The `README.md` is complete and present at the root.
- [ ] `docker-compose.yml` and Dockerfiles are in the root and working.
- [ ] `.env` is NOT checked into GitHub. `.env.example` is present.

## 2. Documentation
- [ ] `docs/architecture.md` is present.
- [ ] `docs/ai-workflow.md` is present.
- [ ] `docs/api.md` is present.
- [ ] `docs/deployment.md` is present.
- [ ] `docs/interview-guide.md` is present.

## 3. Demonstration Preparedness
- [ ] You have Docker Desktop running on your Windows machine.
- [ ] You have successfully run `docker compose up -d --build`.
- [ ] You can log in as `admin@pharma.com`.
- [ ] You have sample Complaint documents (PDFs, txt files) ready to upload to the AI Copilot.
- [ ] You have rehearsed walking through the codebase (especially LangGraph and FastAPI routes).

## 4. Deliverables
- [ ] A 5-10 minute Loom/Screen recording demonstrating the App.
- [ ] The link to the GitHub Repository.
- [ ] The Project Report (if explicitly requested by AIVOA).
