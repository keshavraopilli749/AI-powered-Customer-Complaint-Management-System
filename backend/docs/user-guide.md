# User Guide

Welcome to the AI-powered Customer Complaint Management System.

## Logging In
1. Visit `http://localhost:3000`.
2. Enter your credentials (default: `admin@pharma.com` / `admin`).
3. You will be redirected to the QA Dashboard.

## Creating a Complaint (Manual)
1. Click **"New Complaint"** in the sidebar.
2. Fill out the required fields (Customer, Product, Description).
3. Click **"Save Complaint"**.

## Using the AI Copilot
The AI Copilot allows you to instantly digitize unstructured complaints (e.g., PDFs from doctors, emails from patients).
1. Click **"AI Copilot"** in the sidebar.
2. Upload your file (PDF, Image, TXT).
3. Wait for the LangGraph AI to extract the fields and calculate the regulatory risk.
4. Review the auto-populated form and click **"Save Complaint"**.

## Viewing the Dashboard
The dashboard provides a real-time overview of complaint volume.
- Use the **Filter Panel** to narrow down by High Risk complaints.
- Click the **Export CSV** button to download the current view for regulatory reporting.
