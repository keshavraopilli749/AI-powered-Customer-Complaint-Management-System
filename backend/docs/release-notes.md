# Release Notes

## Version 1.0.0 (AIVOA Submission Release)
*Date: 2026-07-30*

**🎉 Initial Release!**

### Features Added
*   **Enterprise Dashboard**: Built a fully responsive React frontend with CSS Modules, Redux Toolkit, and Recharts.
*   **FastAPI Backend**: Built a high-performance Python backend with SQLAlchemy 2.0 ORM and PostgreSQL integration.
*   **AI Copilot (LangGraph + Groq)**: Integrated an advanced AI state machine capable of extracting Product, Batch, and Description from unstructured documents, alongside calculating Patient and Regulatory risk.
*   **Security layer**: Built JWT-based authentication with `passlib` password hashing and Role-Based Access Control (RBAC).
*   **Testing Suite**: Integrated `pytest` and `vitest` backed by a GitHub Actions CI/CD pipeline to ensure code quality.
*   **Docker Deployment**: Containerized the entire stack using `docker-compose.yml` for 1-click deployment.
